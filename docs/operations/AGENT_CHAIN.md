# ABH worker chain

Current executable transition interface and evidence contracts are in [WORKER_RUNBOOK.md](WORKER_RUNBOOK.md). Current recovery/scheduling instructions are in [README.md](README.md).

Scout → Qualifier → Proof → Solver → independent QA → Submission preparation → Tracking → Learning.

Discovery runs through the existing Vercel runtime and dedicated Supabase. Coding/review workers are invoked by the scheduled agent or an active operator. Public submissions always require specific owner approval. Unknown evidence triggers investigation; historical global Phase 2 audits are not prerequisites for private proof.
